# 画面切り取りフィードバック（v2）

画面上のものを切り取り、一言と赤枠を付けてため、まとめて Claude Code の Code タブに貼る文にする常駐ツール（Snipping Tool の上位互換）。

必要なもの: Windows 10 2004（19041）以降、[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。管理者の権限は要りません。導入は下の「導入・開発」を見てください。画像や一言をネットワークへ送りません。

## 操作

| 操作 | 動作 |
|---|---|
| Ctrl＋Alt＋S（設定で変更可） | 押した瞬間の画面を止めて、切り取り画面を出す |
| ドラッグ | 四角で切り取る |
| W ／ R | ウィンドウ単位（クリックしたウィンドウ）／四角 に切り替える。前回使った方で開く |
| Space | 前回と同じ範囲を切り取る |
| D | 3 秒後に取り直す（押すと閉じるメニューを開いておく時間） |
| Enter | 切り取らずに、ためている分を送る（件数は画面の上部に出る） |
| H | 送った履歴を出す（1 回の送信が 1 行。選んで Enter かダブルクリックで、その送信の .md と画像をもう一度クリップボードへ。Esc で閉じる。トレイの「履歴」でも開く。第3段） |
| Esc | やめる |
| 切り取った後: 一言を書く | 一言の欄に焦点がある。画像の上をドラッグすると赤枠と番号、枠ごとの一言の欄 |
| 枠ごとの一言の欄 | 2 行で開き、打った分だけ伸びる（最大 8 行）。ほかの欄へ移ると 2 行に畳み、右端の ▼ で全文、▲ で畳む。入力中の欄は前に出て、欄どうしはなるべく重ならない所に置く。Shift＋Enter で改行 |
| Enter ／ Ctrl＋Enter ／ Esc | 送る（ためていた分も一緒に） ／ ためるだけ ／ 捨てる（Shift＋Enter で改行） |
| 切り取った後: Shift＋ドラッグ ／ Ctrl＋ドラッグ ／ 右クリック | 矢印 ／ 線（ペン） ／ 最後に描いたものを1つ消す（第2段） |
| 描いている間 | 一言の欄はいったん隠れ、離すと戻る |
| 浮かせた表示（ためている間） | 右下に「ためている n 件・送る・－」。件数で一覧、－で丸に畳む（丸を押すと戻す）、ドラッグで移動（位置を覚える）。切り取りには写らない |
| トレイのメニュー | 送る（予備）・一覧（1件ずつ消せる）・履歴・保存先を開く・設定ファイルを開く・終了（次のサインインまで止める。サインアウト・再起動で戻る）。アイコンの右下の赤い丸の数字はためている件数 |

送ると、送る文（画像の絶対パス・一言・アプリ名・ウィンドウ名・時刻。Chrome・Edge なら URL、画像の中の文字を読めたら「読み取った文字」も）を `send-時刻.md` に書き、その .md と画像をファイルとしてクリップボードに入れる。Code タブに Ctrl＋V で貼ると、画像は添付になり、.md は `@"…\send-時刻.md"` として入って読まれる。1件だけなら「起動キー → ドラッグ → 一言 → Enter → 貼る」。何件かまとめるときは最後以外を Ctrl＋Enter でためる。アプリ名は、四角なら切り取った範囲の中心にあるウィンドウ、W ならクリックしたウィンドウのもの

## 保存先と設定

- 画像: `%LOCALAPPDATA%\SnipFeedback\snips\YYYYMMDD\HHmmss-fff.png`（既定。設定の `saveDir` で変えられる。保存先の外のファイルは送らず消さない。取った日から 7 日を過ぎると消える。ためている間は消さない）
- ためる一覧: `<保存先>\queue.json`（再起動しても戻る）。動作の記録: `<保存先>\app.log`
- 送る文: `<保存先>\YYYYMMDD\send-HHmmss-fff.md`（送るたびに書く。画像と同じく 7 日で消える。ためる一覧や控えが読めず自動削除が止まっている間は、それより古いものも残り、履歴にも出る）
- 設定: `%APPDATA%\SnipFeedback\config.json`（`hotkey`・`delaySeconds`・`saveDir`・`keepDays`・`lastMode`・`badgeX`／`badgeY`〔浮かせた表示の位置〕）。変えたら `install-startup.ps1` を実行し直す（トレイの「終了」は次のサインインまで戻らないため）

## 導入・開発

```
# 起動はタスク スケジューラのタスク「SnipFeedback」（サインイン・ロック解除・スリープ明け・5 分ごと。消えていれば起動し直し、動いていれば何もしない）
powershell -ExecutionPolicy Bypass -File win/tools/install-startup.ps1            # ビルドして %USERPROFILE%\.snipfeedback\app に置き、タスクを登録して起動
powershell -ExecutionPolicy Bypass -File win/tools/install-startup.ps1 -Uninstall # タスクの登録を外して止める
dotnet test win/SnipFeedback.sln                                                  # 単体テスト
```

アイコンは `src/SnipFeedback/app.ico`（16〜256 の多サイズ。exe・ショートカット・トレイ・一覧の窓で共通）。

止まったときは Windows の Snipping Tool（Win＋Shift＋S）と手で書く文章に戻る。ためた画像は保存先に残る。

PC 名やアカウントを変えたら install-startup.ps1 を実行し直す（タスクの合図はユーザー名で登録している。変えたままでも 5 分ごとの合図で起動はする。verify K7）。タスク スケジューラの画面で 5 分ごとの結果が 0x800710E0 と出るのは「動いているので起動しなかった」という意味で、問題ない（verify K8）。
